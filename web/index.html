      关于这套预测

      Sunsetbot 使用 GFS / ECMWF 的等压面云量与位势高度、CAMS 气溶胶资料，沿球面地球上的光路计算云层受光和视线遮挡。指数表示这套独立模型的相对观赏潜力，正在积累实测校准。

      本地时间统一采用 Asia/Shanghai。云的液水、冰含量及细小云洞仍有资料缺口，临近卫星云图与现场观察能帮助判断变化。

      公开研究参考：原作者技术博客 · 数据：Open-Meteo / NOAA / ECMWF / CAMS。
