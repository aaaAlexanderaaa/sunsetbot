# Historical validation assessment

结论：现在应先做历史回测。最值得怀疑的是云目标重建和云自身的发光机制，而非光路积分精度。 代码中已有几处足以造成质量排序颠倒的结构性问题。即使 ERA5 云场接近真实，调节消光系数也难以修复它们。
1. 原站全国图究竟怎么算
原站地图说明确认：使用 GFS/ECMWF 云场、CAMS 气溶胶，综合云量、相态、含水量、云底、照明遮挡、颜色和持续时间，分地区批量生成质量指数（公开标尺约 0–2.5），并为效率简化计算。具体格距、空间聚合和简化公式仍未知。[Rosy Cloud Analysis and Recording] [Rosy Cloud Analysis and Recording]
因此，原站历史预测质量可以作为对照，但尚无依据把全国地图视为城市版算法的直接逐格运行结果。
2. 历史验证：先回答物理模型能否排序
1. 建立完整事件集。 使用原站 2022-06-24 至 2023-12-30 上海全部可用朝晚霞记录，按事件配对六档真实质量。核对缺失、重复、观测覆盖和选择偏差；原站预测只作对照。冻结 0.3.1，严禁根据测试集调整参数。
2. 先做再分析回放。 使用 ERA5 压力层云量、位势高度，加 CAMS EAC4 AOD550，复用现有截面引擎。ERA5 还提供云液水、云冰水，可用于检验固定消光系数。两类资料均覆盖目标年份。[Climate Data Store] [ads.atmosphere.copernicus.eu] 然后用历史 GFS 输入复跑共同样本，区分气象场误差和光学模型误差。
3. 主要评估排序。 用 Spearman、跨等级成对排序正确率、较强火烧云的 AUC 和 Top-K 命中率；六档混淆矩阵仅在训练集确定分档阈值后评估。按月份/连续天气过程分组留出测试，按时间块 Bootstrap 给出不确定性。加入季节性常数、低中高云量＋AOD 的简单基线及原站预测对照。重点检查真实大烧被排低、真实不烧被排高的案例。
4. 做反事实消融。 对全部事件分别替换云目标选择、云照明模型、视角权重、时间聚合和垂直重叠；检查关键交互。对严重错排的约 30–50 个案例，结合观测云属、颜色及可核验照片归因，同时将云场平移约一个网格，测试排序对位置误差的脆弱性。
这首先得到的是给定近真实天气场时的物理重建能力。真正提前 6/24/48 小时的预测能力须另测。Open-Meteo Historical Forecast 是短时次拼接；固定提前量与单次起报需要相应历史预报档案，并核验所需压力层字段覆盖，不能混用为同一种提前量。[open-meteo.com] [open-meteo.com] [open-meteo.com]
3. 代码中最可能导致排序错误的四处
第一，cloudDecks() 提前删掉高云。 假设低云和高云各覆盖 60%，中间有晴空层：由于 below 保存历史最大云量，高云不会生成目标。但斜视线可能从低云旁边看到高云，后续视线遮挡积分已有能力处理这种情况。当前实现会系统性漏算部分多层云霞光。三个重叠敏感性情景也都保留此垂直最大重叠假设。
第二，把透射率当作云的亮度。 targetLight() 计算阳光穿过云和大气后的剩余能量，却缺少云粒子向观察方向散射阳光的源项。云厚度、冰水含量、受光云顶/侧面会改变亮度；薄云高透射和厚云强散射可能被错误排序。这是比 680/550/440nm 取样更根本的缺项。ECMWF 的辐射方案也明确使用云量、液水、冰水和散射性质。[ECMWF]
第三，天空面积权重失真。 现有权重以 min(1, …)/π 截断。以高度 2km、中心横向宽度 25km 的云片为例，代码赋权约 0.318，而对应二维截面的准确角度积分约 0.90。不同距离与高度受到不同程度的扭曲。三方位截面还遗漏侧方云系。
第四，最大瞬时分数代替整场质量。 max(score) 奖励短暂峰值，而原站明确考虑持续时间。先比较最大值、持续时间加权积分及高分连续时长；同时检查先平均随机透射率再开平方造成的偏亮效应。
4. 物理近似的取舍
优先保留： 球面地影、太阳与观察者双光路、条件云概率积分的遮挡思想，以及完整输入留存。这些是有价值的物理与工程基础。
优先更换： 云目标生成与垂直遮挡逻辑、只看云底的照明模型；随后修正视角面积和时间聚合。利用 ERA5 云液水/冰水检验简化云散射源项。
暂缓精调： 水平相关长度 50km、AOD 垂直尺度、三个波长、指数增益和标签阈值。AOD 与能见度的重复惩罚也应单独消融。
最终决策标准是：改动能否在留出日期中持续减少真实质量的严重错排，并稳定优于简单分层云量基线。 若复杂光学模型在近真实天气场下仍输给基线，应先简化辐射近似、改善云表示，再投入更高计算精度。
最大的剩余边界是观测标签覆盖率，以及粗网格云量缺失的云形态信息。这决定了回测能解释多少错误，也决定未来应输出确定性指数还是带概率的观赏机会。
